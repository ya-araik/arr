# Занятие: Методы массивов и стрелочные функции (Лямбды)

На этом занятии мы кратко повторим основы JavaScript, разберем два мощных инструмента для работы с массивами — `slice()` и `splice()`, а также закрепим использование стрелочных функций на практике.

---

## 🧭 Краткое повторение (Что мы уже знаем)

1. **Переменные:** Хранилища данных (`let` для изменяемых значений, `const` для констант).
2. **Математические действия:** Простая арифметика (`+`, `-`, `*`, `/`, `%`).
3. **Условия (`if / else`):** Разветвление логики кода в зависимости от истинности выражения.
4. **Функции:** Блоки кода, которые можно вызывать многократно.
5. **Стрелочные функции (Лямбды):** Сокращенный синтаксис функций. 
   * *Обычная:* `function(item) { return item; }`
   * *Стрелочная:* `(item) => { return item; }` или еще короче: `item => item`
6. **Массивы (Основы):**
   * Создание: `let arr = [1, 2, 3];`
   * Доступ по индексу (начинается с 0): `arr[0]` (первый элемент).
   * Добавление в конец: `arr.push(4);`
   * Удаление с конца: `let last = arr.pop();`
   * Перебор элементов: `arr.forEach(item => { ... });`

## 📘 Новая тема: Методы массивов `slice()` и `splice()`

До этого момента мы умели добавлять и удалять элементы только с конца массива. Сегодня мы научимся копировать части массива и «вырезать» или заменять элементы в любом месте.

### 1. Метод `slice()` — безопасное копирование
Метод `slice` (переводится как *«отрезать кусочек»*) создает **новый массив**, в который копирует элементы из старого. Оригинальный массив **не изменяется**.

* **Синтаксис:** `массив.slice(откуда_начать, до_куда_не_включая)`
* **Важно:** Второй параметр указывает на индекс, перед которым нужно остановиться. Сам этот элемент в новый массив не попадет.

```javascript
let fruits = ['яблоко', 'банан', 'груша', 'апельсин', 'киви'];

// Копируем элементы с индекса 1 по индекс 3 (не включая 3, то есть индексы 1 и 2)
let subList = fruits.slice(1, 3); 

console.log(subList);  // Выведет: ['банан', 'груша']
console.log(fruits);   // Выведет оригинальный массив, он НЕ изменился!

// Лайфхак: если не указать второй параметр, скопируется всё до конца массива
let fromBanana = fruits.slice(1); // ['банан', 'груша', 'апельсин', 'киви']
```

### 2. Метод `splice()` — изменение и замена (меняет оригинал!)
Метод `splice` (переводится как *«срастить»/«склеить»*) — это «швейцарский нож». Он **изменяет оригинальный массив**: удаляет элементы, добавляет новые или делает и то, и другое одновременно.

* **Синтаксис:** `массив.splice(с_какого_индекса, сколько_удалить, что_вставить1, что_вставить2...)`

**Пример A: Только удаление**
```javascript
let plan = ['Проснуться', 'Поесть', 'Помыть кота', 'Поспать'];

// Удалим "Помыть кота" (индекс 2), удаляем ровно 1 элемент
plan.splice(2, 1); 

console.log(plan); // Выведет: ['Проснуться', 'Поесть', 'Поспать'] (массив изменился!)
```

**Пример B: Удаление и замена**
```javascript
let team = ['Аня', 'Ваня', 'Петя'];

// Вместо Вани (индекс 1) запишем Олю и Диму (удаляем 1 элемент, вставляем 2 новых)
team.splice(1, 1, 'Оля', 'Дима');

console.log(team); // Выведет: ['Аня', 'Оля', 'Дима', 'Петя']
```

**Пример C: Вставка без удаления**
```javascript
let colors = ['Красный', 'Синий'];

// Вставляем 'Зеленый' на индекс 1, при этом удалять ничего не нужно (указываем 0)
colors.splice(1, 0, 'Зеленый');

console.log(colors); // Выведет: ['Красный', 'Зеленый', 'Синий']
```

## 🚀 Практическое задание: «Менеджер космического груза»

**Легенда:** Вы работаете программистом на грузовом космическом корабле. Весь груз хранится в отсеках в виде массива. Вам нужно написать программу управления этим грузом с использованием стрелочных функций.

### Исходные данные
Создайте массив с начальным грузом корабля:
```javascript
let cargoHold = ['Топливо', 'Кислород', 'Провизия', 'Кристаллы', 'Инструменты'];
```

### Задачи для выполнения:

1. **Проверка безопасности (`forEach`, условия, стрелочные функции):** 
   Капитан хочет знать, что лежит на корабле. С помощью метода `forEach` и **стрелочной функции** переберите массив. 
   * Для каждого груза выведите в консоль сообщение: `«Внимание: груз [Название_груза] проверен»`. 
   * Если встречается груз `'Кристаллы'`, дополнительно выведите строкой ниже: `«⚠️ Внимание! Обнаружен ценный груз!»`.

2. **Срочная разгрузка (`pop`):**
   Корабль слишком тяжелый! Удалите **последний** элемент из массива `cargoHold`. Выведите в консоль фразу: `«Разгружен последний отсек: [Название_удаленного_груза]»`.

3. **Секретная миссия (`slice`):**
   Ученые на борту хотят изучить грузы с **1-го по 3-й индекс (включительно)**. Создайте **новый** массив `scienceCargo` с этими элементами, используя метод `slice`. 
   * Выведите массив `scienceCargo` в консоль. 
   * Выведите оригинальный массив `cargoHold` в консоль, чтобы убедиться, что он не изменился.

4. **Атака космических пиратов (`splice`):**
   Пираты пробили обшивку корабля в районе **индекса 1** и украли **два** отсека с грузом. Удалите 2 элемента, начиная с индекса 1, с помощью метода `splice`. Выведите изменившийся массив `cargoHold` в консоль.

5. **Контрабанда (`splice`):**
   Корабль пришвартовался к космической станции. Капитан решил тайно добавить в массив груза элементы `'Золото'` и `'Детектор лжи'` строго на место украденных пиратами вещей (то есть вставить их на **индекс 1** без удаления текущих элементов). Выведите финальный массив `cargoHold`.
